# Portfolio

Personal portfolio site for **Gaurav Manju**, an MSc Artificial Intelligence with Industry student at the University of Leicester.

**Live site:** https://GauravManju.github.io/portfolio

Built with **React** and **Vite**, and deployed on **GitHub Pages**.

## Run locally

```bash
git clone https://github.com/GauravManju/portfolio.git
cd portfolio
npm install
npm run dev
```
